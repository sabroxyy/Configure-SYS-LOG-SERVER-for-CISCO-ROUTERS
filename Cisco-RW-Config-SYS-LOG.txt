=============================================================
Cisco Router Config (IOS / IOS-XE)
=============================================================

Replace <syslog-server-ip> and <interface> with your values.

conf t
 service timestamps log datetime msec localtime show-timezone
 logging buffered 100000 informational
 logging trap informational
 logging source-interface <interface>
 logging host <syslog-server-ip> session-id hostname
 logging on
 !
 ! Send every configuration change to syslog (audit trail)
 archive
  log config
   logging enable
   logging size 1000
   notify syslog contenttype plaintext
   hidekeys
end
write memory

=============================================================
Optional: send over TCP instead of UDP (default is UDP 514)
=============================================================

conf t
 logging host <syslog-server-ip> transport tcp port 514 session-id hostname
end

=============================================================
Verify on the router
=============================================================

show logging
send log "syslog test from router"
