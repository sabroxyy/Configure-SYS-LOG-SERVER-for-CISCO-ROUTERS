=============================================================
Linux rsyslog Server Config (CentOS / RHEL 7+)
=============================================================

# yum -y install rsyslog
# vi /etc/rsyslog.conf

=============================================================
1. Enable reception on port 514
=============================================================

Uncomment (remove the leading "#") from these lines:

From:
# Provides UDP syslog reception
#$ModLoad imudp
#$UDPServerRun 514

# Provides TCP syslog reception
#$ModLoad imtcp
#$InputTCPServerRun 514

To:
# Provides UDP syslog reception
$ModLoad imudp
$UDPServerRun 514

# Provides TCP syslog reception
$ModLoad imtcp
$InputTCPServerRun 514

=============================================================
2. One log file per remote device
=============================================================

Add at the START of the "RULES" section, before any other rule:

$template Remote,"/var/log/syslogs/%fromhost-ip%.log"
if $fromhost-ip != '127.0.0.1' then ?Remote
& stop

Notes:
- The "if" keeps the server's own logs in /var/log/messages.
- "& stop" replaces the old "& ~" syntax (deprecated since rsyslog 7).

Save and quit:  :wq

Check the config syntax before restarting:

# rsyslogd -N1

=============================================================
3. Restart and enable rsyslog
=============================================================

# systemctl restart rsyslog
# systemctl enable rsyslog

Verify it is listening on 514:

# ss -tulnp | grep 514
  (or on older systems: netstat -antup | grep 514)

Expected output (similar to):
udp   UNCONN  0  0  0.0.0.0:514  0.0.0.0:*  users:(("rsyslogd",pid=1467,fd=3))
tcp   LISTEN  0  25 0.0.0.0:514  0.0.0.0:*  users:(("rsyslogd",pid=1467,fd=5))

=============================================================
4. Firewall
=============================================================

If a hardware firewall sits between the routers and this server,
ask for TCP & UDP 514 to be opened.

If firewalld is enabled on the server:

# firewall-cmd --permanent --add-port=514/udp
# firewall-cmd --permanent --add-port=514/tcp
# firewall-cmd --reload

=============================================================
5. Validate
=============================================================

# ls -l /var/log/syslogs/
# tail -f /var/log/syslogs/<router-ip>.log

If nothing arrives, check:
# tail -f /var/log/messages          (rsyslog errors)
# tcpdump -ni any port 514           (are packets reaching the server?)
